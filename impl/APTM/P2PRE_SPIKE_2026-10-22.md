## 0. 结论（先读）

**1) 根因已被受控实验锁定（强于 P1 的间接证据）。**
在**无损** tag-cartesian 产物（decode 六项全 true、dec.off 与基线一致）上，仅在
decode 进程里给重建顶点位置注入 **±1 个量化单位**（= bbox/4096 ≈ 2.4e−4 相对值，
比 polar 典型误差小 1–2 个数量级）的确定性偏移，结构即失效：
counts/connectivity/topology 全 false、剩下 19,578/19,851 顶点、坐标仅 11,102 个
匹配（§3.2）。⇒ tag sv=3 的拓扑推断
（`normalize_proxy_to_min_position_vertex` → polygon v0 / fan 对角线 / Frenet frame t1）
是 **lossless-only 捷径**；任何有损几何 coder 在该约定下都解不出有效网格。
**polar 数学与 3-bit 精度均无罪。**

**2) P2-pre 有一个可实现的 decoder-side 坐标无关注解（Design A），但要 ~550 LOC 且单独不够。**
fan triangulation 在 coarser mesh 里留下纯拓扑签名：encoder 从 `polyVerts[0]`
（= position-normalize 后的 v0）做 v0-fan，N−2 个 fan 三角形全部含 v0、内部对角线
带 `isAdded()`；⇒ decoder 可以仅凭拓扑恢复 v0/ring/对角线（valence≥5 唯一；
valence=4 两个候选；valence=3 无 fan）。降级成本已量化（§5）：
全 v0 索引流 **2.099 bpv**（不可接受），仅歧义面兜底 **0.539 bpv**。
但即便拓扑恢复正确，**帧的数值仍依赖位置**（n/t1 由当前几何算出）⇒ 还要
**P2-sim（编码端解码模拟/不动点）**；P2-pre 单独不能把 polar 变成可解码。

**3) 更省的替代架构（Arch-2，建议主路线）：位置对称的编码端模拟。**
encoder 用「decoder 将会看到的位置」做所有位置相关决策（normalize / 帧 / pred_c2 /
r1 链），迭代到不动点后用真实 decode 验证；不动点处两端位置一致 ⇒ 拓扑推断自动
一致、帧自动一致。它**同时覆盖 P2-pre + P2-sim**，无歧义面、无 side-stream，
~700–1,000 LOC，风险集中在不动点收敛（§4.3）。
⇒ 建议：**P2-pre 不再单独做**；下一轮先做 Arch-2 的最小 spike（只改 normalize 位置
来源 + 一轮迭代），P3 并行推进。

**4) 硬顶 23.14 的路径算术（推荐继续 P3）。**
- 可解码现状 tag-frenet 29.164 = C 8.955 + G 17.773 + container/overhead 2.44。
- **P3**（真 A&D connectivity）C→4.9–5.5（−3.5~−4.0）+ 无损几何熵码 −0.3~−0.6 ⇒ ~24.0–24.6，**仍高于硬顶 23.14**。
- 必须叠加 **polar**（G 17.77→13.72，−4.05）⇒ 5.0+13.7+2.4 ≈ **21.1–21.6（1.19–1.21×，过 1.30 硬顶）**。
- ⇒ polar + P3 两者都不可少；P3 的 deterministic gate 规则同时是无坐标拓扑推断的天然载体，
  可与 Arch-2 共用同一套 ring/diagonal 层。

**5) 纪律核对：默认 APTM 路径 84,496 B / 34.052088 bpv / artifacts md5 与冻结审计逐字节一致**
（本轮所有改动 env 门控）；未用 RETRI_TAG/Conquest、未降 q。

## 1. 实验方法

### 1.1 为什么用「噪声注入」而不是继续改 polar encoder

P1 是间接证据（rounds=1 结构有效、rounds=2 起坏、θ/φ 近无损 1,048,576 级仍坏）。
本轮做**单变量受控实验**：产物仍是**无损** tag-cartesian（编码/连通性/残差全部合法），
只改 decode 进程里重建位置的数值（`impl/APTM/decompress/APTMSimLossyDeserializer.h`）：
- 若结构失效 ⇒ 失效只能来自位置值本身 = coordinate-based 拓扑推断；
- 若结构仍有效 ⇒ P1 推断被否证。

噪声只扰**插入顶点**（默认 `PMSF_APTM_SPIKE_NOISE_ALL=0`；base mesh 保持精确，
对应真实码流 base 无损、只有 geometry residual 有损），±delta 由 poolId 哈希决定
（确定性可复现）。控制组/噪声组用同一份无损产物、同一二进制、同一 decode 配置。

### 1.2 预先登记的判据
`delta=1` 使 counts/connectivity/topology 任一失效 ⇒ 根因锁定；`delta=4` 仍全 true ⇒ 否证。

### 1.3 附带量化
同一 deserializer 每轮对每个面比较 `argmin_lex(量化坐标)` 与
`argmin_lex(量化坐标+确定性偏移)` 的环上顶点，统计 d∈{1,2,4,8} 的 **proxy 翻转率**
（=「v0 只有坐标相关来源」的直接量化 + side-stream 成本输入）。
另在 collector 里统计 **polyFace valence 分布**（`[APTM-Tag valence]`），
给出 v0 side-stream 的精确代价。

### 2.1 控制组（无损产物、无噪声）
`counts_ok=connectivity_ok=topology_ok=nearest_geometry_ok=coordinate_remap_complete=true`，
test_vertices=19,851，coord_match_max=3.78e−5。⇒ 实验装置本身不破坏解码。

### 2.2 噪声注入（单变量因果实验）

|---|---:|---|---|---:|---:|---:|
| control | 0 | — | 全 true | 19,851 | 19,851 | 3.78e−5 |
| noise_d1 | 1 | 仅插入顶点 | **全 false** | 19,578 | 11,102 | 1.75e−3 |
| noise_d2 | 2 | 仅插入顶点 | 全 false | 19,556 | 9,928 | 1.75e−3 |

| noise_d1_all | 1 | 全部顶点 | 全 false | 19,645 | 6,400 | 1.75e−3 |
| noise_d4_all | 4 | 全部顶点 | 全 false | 19,570 | 1,535 | 1.75e−3 |
| polar_ref（对照） | — | 真实 polar 产物 | 全 false | 19,104 | 6,524 | 1.75e−3 |

**判据成立：±1 量化单位（2.4e−4 相对 bbox）就足以破坏结构解码。**
polar 的典型误差远大于此，因此 polar decode 失效与 polar/3-bit 精度无关，
**根因 = 坐标依赖的拓扑推断**。

### 2.3 proxy 翻转率（150 轮累计）

```
faces(轮×面)=519,216  avgRing=3.00（decode 时参与 normalize 的面均为三角形）
flipRate(d=1)=1.306%  flipRate(d=2)=2.566%  flipRate(d=4)=4.808%  flipRate(d=8)=9.026%
```

要点：**σ=1 单位时只有 1.3% 的面 proxy 翻转，却足以让整个 decode 结构崩掉**
⇒ 失效是**级联**的（一次 v0 翻转 ⇒ fan 对角线/ring order/tag evolution 分叉 ⇒
后续轮次的 proxy/tag 连锁偏离），不存在「容忍少量翻转」的余地。
⇒ 任何 side-stream 兜底都必须覆盖**所有**会翻转的面（而 encoder 不知道 decoder
会翻哪些，除非做 Arch-2 的位置模拟），这条进一步支持 Arch-2 主路线。

### 2.4 valence 分布与 v0 side-stream 成本（polyFaces=19,222）

| valence | 3 | 4 | 5 | 6 | other |
|---|---:|---:|---:|---:|---:|
| polyFaces | 3,853 | 4,608 | 5,590 | 5,171 | 0 |
| 占比 | 20.0% | 24.0% | 29.1% | 26.9% | 0% |

- 全 v0 索引（每面 `log2(valence)` bits）：**Σ=41,669 bits = 5,209 B = 2.099 bpv**。
- 仅歧义面兜底（Design A：valence≥5 拓扑唯一 ⇒ 0 bit；valence=4 ⇒ 1 bit；
  valence=3 ⇒ 1.585 bit）：**0.557 bits/face ≈ 1,338 B ≈ 0.539 bpv**（tag 消歧后还可再降）。
- 参考：polar 25.095 + 0.539 ≈ **25.63 bpv**（仍在 P1 目标区间上沿）；
  if 用全 v0 流则 27.19（仍优于 tag-frenet 29.164，可作应急兜底）。

## 3. 根因链（code-level，供 P2/P3 实现直接引用）

1. encoder `PCLTTMTagEliminateOperator::eliminate`（impl/PCLTTM/elimination/）：
   `remove_point(h)` → 对 polyFace 做
   `normalize_proxy_to_min_position_vertex(mesh_->bboxMin, mesh_->f_quantStep)`
   ⇒ **v0 := 量化坐标字典序最小的环顶点**；随后 evolve tag（ring 顺序从 v0 起）、
   `triangulate(proxyHalfedge)` 从 v0 做 **v0-fan**（对角线 v0–v2…v0–v_{n−2}，全部
   `setAdded()`；polyFace 对象复用为第一个 fan 三角形且保留 splittable）。
2. encoder `PCLTTMTagSymbolCollectOperator::collect` 入口：对**所有面**再做一次
   position-normalize（此时面已是三角形：proxy = 三角形 3 顶点中坐标字典序最小者）
   ⇒ Frenet frame 的 n/t1 也由这个坐标 proxy 决定。
3. decoder `PCLTTMTagSymbolReadOperator::collectFromDecoded`：对 BFS 首访面做同样的
   `normalize_proxy_to_min_position_vertex(bboxMin_, f_quantStep_)`，再从
   `proxyH->next()->next()` 推断 fan 对角线、`setPolyValence`、`setRemovedVertexPosInt`。
4. ⇒ 只要 decoder 的量化整数坐标与 encoder 不同（任何 lossy 几何），
   `argmin` 可能换顶点 ⇒ v0/fan/ring/frame 全部偏离 ⇒ fence-post 级联失败（§2.2）。
   lossless 时 q_dec==q_enc 才成立。

## 4. 设计选项与推荐

### 4.1 Design A（decoder-side 坐标无关 fan 恢复）— 可行，但单独不够

恢复规则（纯拓扑；fan 三角形从 isPoly=1 的首个 fan 三角形出发、跨 `isAdded()` 内部边收集）：

| valence n | fan 结构 | v0 恢复 | 歧义 |
|---|---|---|---|
| ≥5 | n−2 个三角形 | 所有三角形顶点交集中的**唯一**顶点 | 无（0 bit） |
| 4 | 2 个三角形共享对角线 | 公共顶点 2 个候选（fan 中心 vs 对角线远端） | 1 bit（或 tag 模式消歧） |
| 3 | 单三角形（triangulate 提前 return，未 split） | 拓扑不可辨（3 候选） | log2(3)=1.585 bit（或 tag 消歧） |

ring 顺序 = 从 v0 沿 patch 边界走一周；对角线列表 = patch 内 `isAdded() &&
end_vertex()==v0` 的半边按 ring 索引升序（与父类推断顺序一致）；
再把 `f->proxyHalfedge()` 设为 v0→v1 后走父类原有 residual/reconstruct 流程。
LOC ~550（reader copy ~350 + encoder 帧约定 ~200），不需要改 impl/PCLTTM。**但**：恢复出 v0/ring 只解决「拓扑从哪开始」；帧的**数值**
（n/t1）仍由当前几何位置算出，encoder=原始位置 vs decoder=重建位置 ⇒ 帧方向不同
⇒ 反投影残差错 ⇒ 几何误差跨轮反馈。⇒ Design A + P2-sim 两者都要。

### 4.2 Arch-2（建议主路线）：位置对称的编码端模拟（subsumes P2-pre + P2-sim）
- encoder 在编码几何前先获得「decoder 将会拥有的位置」P_r（每 LOD 每顶点）。
- 所有位置相关决策（eliminate 的 normalize、collect 的 fan proxy、帧、`pred_c2`、
  barycenter 预测、r1 链）都用 P_r；残差 = 目标位置 − prediction(P_r)；
  再模拟 decode 得 P_{r+1}，迭代到不动点（P 稳定），最后用**真实 decode** 验证。
- 不动点处 encoder 的 normalize/帧与 decoder 用同一组位置 ⇒ 拓扑推断自动一致
  （**不再需要任何坐标无关注解/side-stream**），帧也一致。
- LOC 700–1,000（3 遍编排 ~300；collector 位置注入 ~250；不动点/验证 ~200），
  风险：收敛性（预测=加权平均，通常收缩；但量化误差可能振荡）、双遍内存（ContextPool
  不释放，需放大 `PMSF_POOL_*` 并在报告里注明）、消除顺序必须在多遍间冻结。
- 与 P3 的关系：P3 的 deterministic gate 规则本身就能提供坐标无关的 ring/v0，
  若先做 P3，Arch-2 只需承接帧/预测位置对称；两者共享同一层。

### 4.3 结论：P2-pre 的「独立坐标无关注解」不值得单独做
- 只做它：polar 仍不可解码（帧问题），代价 ~550 LOC；
- 做 Arch-2：一次覆盖拓扑+帧，代价 ~700–1,000 LOC，且无歧义面/side-stream。
- 因此建议 **P2-pre 直接升级为 Arch-2**，并把「Design A 的 fan 恢复」保留为
  Arch-2 不动点不收敛时的 fallback（fan 恢复逻辑在 P3 的 deterministic replay 里还会复用）。

## 5. 是否继续 P3：建议 + 排期（更新）

**建议继续 P3，并与 Arch-2 并行/交错：**

1. **P3（优先，2–3 轮，1,500–2,500 LOC，高风险）**：真 A&D valence/null_patch
   connectivity。它的 deterministic gate/valence 重三角化规则 = 天然的坐标无关
   ring/v0/diagonal 来源，直接吃掉 P2-pre 的拓扑目标；同时 C 8.955→4.9–5.5。
   验收：默认 APTM 84,496 B/34.052088 不变 + q12 horse19k decode 六项 true
   + C 分量降到 ~5 + 证据 CSV。
2. **Arch-2 最小 spike（1 轮，先只做「normalize 位置来源改为 decoder 位置」+
   1 次迭代）**：在 P3 进行时用现有 tag-cartesian 验证不动点收敛与 decode 有效性；
   成功后接 polar，目标可解码 polar **25.1–25.6 bpv**。
3. **P4（最后，0.5 轮）**：base/LOD/container/rounds −0.3~−1.0 bpv。

**风险与止损**：P3 若 2 轮内 C 降不到 6.0 以下，回退保留 tag-frenet 29.164 作为
阶段一可解码证据；Arch-2 若 2 次迭代不收敛，回退 Design A + 歧义 side-stream
（polar ≈ 25.6，代价 +0.54 bpv）。全程不得用 RETRI_TAG/Conquest、不得降 q。
