证据脚本：`scripts/tests/test_aptm_audit.sh`（产物默认在 `/tmp/wsb2/aptm_audit/`）
本轮结论：**FAIL**（34.052 bpv，硬顶 23.14，需 −32%）。论文的 polar θ/φ 3-bit 几何 coder
与 A&D valence-driven connectivity **完全不存在的 coder**（不是未接线），本轮按 Lead 裁决

## 1. 忠实路径与基线（可复现）

```
algorithm=APTM（默认：不设 PMSF_APTM_USE_RETRI_TAG / PMSF_APTM_USE_CONQUEST）
q12, horse19k, rounds=150, adjustment=true（WS-B 定标的 default 口径）
art_* = 84,496 B = 34.052088 bpv（论文 17.80 → 1.913×）
decode: valid=true, connectivity_ok=true, topology_ok=true, nearest_geometry_ok=true,
        coord_match_max_dist=3.78e-5
anchors: 139（CurvatureHysteresisDetector，hysteresis 1.7/1.2，每轮重新标记不可删）
```
别名警告（禁用）：`PMSF_APTM_USE_RETRI_TAG=1` → RD_TAG 协议，产物逐字节等于 RD
（26.036/22.609）；`PMSF_APTM_USE_CONQUEST=1` 在本口径下实测**与 default 逐字节相同**
（md5 相同，见 `aptm_audit.csv` 的 conquest_bridge_same_bytes=true），即 Conquest bridge
没有被激活，不构成另一条可汇报路径。

## 3. 论文组件逐项审计（实现状态）

| 论文组件 | 状态 | 证据 |
|---|---|---|
| anchor 检测（主曲率 + hysteresis） | ✅ **已实现**（1:1 移植：`src/feature/CurvatureHysteresisDetector.h` + `impl/APTM/AnchorPreprocessor.h`，每轮重标 non-removable） | 实测 139 anchors；`AnchorPreprocessor` 注释明确 1:1 port |
| anchor 保锚 → 进 base mesh | ✅ 已实现（markAnchor/不可删 → base mesh 携带） | baseV=604，decode 后 anchors 位置正确 |
| **A&D valence-driven conquest（decimating/cleaning + 重三角化规则 + null_patch，含 anchor null_patch）** | ❌ **缺失** | default 路径是 `OptimizedSymbolCollectOperator`（QEM 式 facet/edge/point 三段流，见 `src/algorithm/ISimplificationAlgorithm.h:318` 默认 collector）；connectivity 13.17 bpv = 2.69× 论文 C |
| **Frenet 局部系 + polar 3D 坐标（θ/φ 3-bit）+ 法向/切向不同比特分配** | ❌ **完全缺失** | `PMSF_APTM_REQUIRE_PAPER_EXACT=1` / `..._REQUIRE_POLAR_GEOMETRY=1` 直接 throw：`APTM polar geometry and anchor-aware reconstruction are not implemented yet`（见 `impl/APTM/compress/APTMConquestSymbolCollectOperator.h::requireAPTMPaperExactIfRequested`） |
| anchor-aware reconstruction | ❌ 缺失（只有 side-metadata：`impl/APTM/boundary/APTMPMSFBoundary.h` 写 `polar_geometry=0 / anchor_aware_reconstruct=0` 等 flag，无 coder） | 同上；`APTMPMSFBoundary.h` 的 10 个 side channel 全为占位 int |
| APTMConquest 桥 | ⚠️ 不是 APTM：`PCLTTMStrictSymbolCollectOperator` 的别名（BlobLayout CODEC_026），带 locator sideinfo（strict RD 同源，~200+ bpv 量级），paper-exact 时 throw | `impl/APTM/compress/APTMConquestSymbolCollectOperator.h` |

参考：框架内 A&D 风格的现成实现是 **PCLTTM Tag 路径**（PCLTTM = Alliez-Desbrun 2001，
即 APTM 论文的 base algorithm）：q12 horse19k rounds50 = 27.469 bpv，
分量 valence 4,163 B + fusedFaceSym 15,610 B（C=7.97 bpv）+ residual 45,422 B（G=18.30）+ container。
即 **框架的 A&D 实现本身也是论文 A&D C=4.61 的 1.73×**（fusedFaceSym 4-元/face 近似），
这决定了 APTM 的落地只能分两步走（见 §4）。

## 4. 到 23.14 的实现计划（LOC/风险/轮次）

目标分解：34.05 − 10.91 bpv。最省路是 **换用 patch-conquest 底部 + 补 polar 几何**：

| # | 组件 | 说明 | LOC | 风险 | 轮次 | 预期 bpv |
|---|---|---|---|---|---|---|
| P1 | `APTMTagSymbolCollectOperator`（`impl/APTM/compress/`）：继承 `PCLTTMTagSymbolCollectOperator`，保留其 valence/fusedFaceSym 与 v0-fan 重建，**只把 residual 流换成 polar 几何 coder**（共享代码不动，PCLTTM 默认字节不变）；decoder 对应 `impl/APTM/decompress/` 反演 | 借力 A&D-style 连通性（C 13.17→7.97，−5.2 bpv） | 800–1,200（enc 400–600 / dec 400–600）+ 测试 | 中（新 collector 但复用父类 BFS/重建路径；不碰 PCLTTM 默认路径） | 1–2 | 27.469 − (18.3→15) ≈ **24–25** |
| P2 | polar 几何 coder 完整版：Frenet 系（n=patch 法向、t1=gate 向量切向投影、t2=n×t1；双端用**量化整数位置**构造，避免 RD 本轮踩的 frame 不对称坑）+ 3D polar (θ,φ) + **θ/φ 3-bit 量化** + 半径/法向分量全比特 + bit-plane/上下文 RC。⚠️ 论文 §4.2 明确 tangent 3-bit 是**有损**（title 的 lossless 指 connectivity/12-bit 预量化之上的可实现口径），质量门禁需用论文自己的 RMS/bbox 指标而不是 nearest_geometry 1e-3 | 几何 15 → ~13.5–14.5（−0.5~−1.5 bpv） | 500–800（enc）+ 300–500（dec） | 中高（有损、质量口径要另行登记） | 1–2 | **23.5–24.5** |
| P3 | A&D 真码流连通性（valence code + null_patch + Fig.1 重三角化规则推断，去掉 fusedFaceSym）：decoder 用 valence/规则确定性 replay | C 7.97 → 4.9–5.5（−2.5~−3 bpv） | 1,500–2,500（enc+dec，含 replay 对齐；风险类似 RD strict 的 face 选择问题） | **高** | 2–3 | **20.5–21.5（PASS）** |
| P4 | base/LOD 收紧（baseV=604 的 6,610 B compact + 2,566 B LOD；rounds 扫描/更紧凑 base mesh 存储） | −0.5~−1.5 bpv | 100–300（storage 域，需 Lead 分派） | 中 | 0.5 | 结构收益 |

结论：**本 session 不可达** 23.14。P1+P2 是 2–3 轮可交付的“已缩小”路径（~24），
但要过硬顶必须做 P3（真 A&D 连通性 coder），它与 RD 的 traversal 重写是同一类高风险工作。
