## 3. 论文组件逐项审计

1. **PGS（prioritized gate selection）** — **名存实亡**：`impl/RD/RDErrorMetric.h` 的
   6 级 tag-priority 梯度是死代码 —— `vpTag` 只在 `registerProperties()` 里初始化为
   UNTAGGED（RDErrorMetric.h:86），忠实 rd_tag 路径上没有任何 `setTag`（只有
   `impl/common/patch/RDPatchPipeline.cpp` 的 strict/patch 路径设 tag，default 不走），
   且 `calculateError()` 的 `from_null` 从未被置 true ⇒ **每个 halfedge 的 cost 恒为 2.0**，
   排序实际由 `HalfedgeSelectionQueue` 的堆插入顺序决定（见 §6-F4）。
2. **curvature prediction（§3.1 Eq.2–3）** — 代码在跑但**实质 no-op**：
   `PMSF_RD_PAPERPRED_DIAG=1` 实测 mean|pred_c2|=1.92 vs mean|r1|=17.64（quant units）；
   λ 网格扩到 {0,0.5,1,1.5,2,3,4,6,8} 后 per-layer best-λ 只省 **54.9 B（0.02 bpv）**；
   按论文 Eq.(2) 正确 Laplacian 式（相邻顶点自身 r_i，当前顶点以 v̂_c 代）在同一 BFS
   时刻重算：mean|pred|=8.25，但 enc 从 17.22 恶化到 20.05，Shannon **+1,346 B**。
   根因：本 traversal 下 r1 是 QEM 选中顶点的法向偏移，与粗网格相邻顶点的 Laplacian 不相关；
   论文收益依赖其 A&D patch conquest 的平滑插入顺序。**该组件在本路径不可实现出收益。**
3. **topology-based KLT（§3.2）** — 代码完整存在（`PMSF_RD_USE_KLT=1`，enc+dec 自描述
   basis 表），实测 residual **+803~+1,404 B（变差）**，不采用。
4. **bitplane/上下文熵编码（§3.3）** — 已实现且已到界（44,658 vs Shannon 44,199）。
5. **自适应/有损残差截断** — 有损，禁用。
6. **局部直角系投影（Eq.3）** — 本轮实现（§4），是唯一有正收益且可 lossless 的论文组件。

## 4. 本轮实现：可逆局部 Frenet 系残差（论文 Eq.3）→ 25.184 bpv, decode 全绿

### 4.1 进程（两阶段，证据驱动）
- **task-4**：恢复 sv=7（3 流）/sv=8（4 流：+exact correction）发射路径
  （`impl/RD/compress/RDTagSymbolCollectOperator.cpp` schemeVersion/stream count/
  correction 流 + `impl/RD/decompress/RDTagSymbolReadOperator.cpp` flags/correction 解析）。
  当时 sv=7 = 62,414 B/25.15 bpv 但 decode coord_max=1.75e-3 / topology false。
- **task-13 根因 1（frame 不对称）**：encoder `residualFrenetFrame` 用原始浮点位置，
  decoder 用量化重建位置（落在 (q+0.5)·step 半格上），法向/门向量差 ~quantStep/edgeLen
  ≈5%。修复：两端 `residualFrenetFrame`/`frenetFrameNormal`/`frenetGridPoint` 统一用
  **量化整数位置**（与 `Mesh::floatPosToInt/intPosToFloat` 逐位同源）；decoder 传基类
  `bboxMin_/f_quantStep_`。全部 env-gated（只在 frenet 分支被调用）⇒ 默认字节不变。
  **证明**：sv=8 exact 修复后 decode coord_max=3.78023068196e-05（= 基线）且六项全 true。
- **task-13 根因 2（float 旋转不可逆）**：sv=7 的 float 旋转 + round 不可逆；每层残差
  ±0.5~1 量化单位的损失沿 50 层预测链累积到 ~39 quant unit（1.75e-3）⇒ sv=7 仍 FAIL；
  sv=8 exact correction 能修好但 correction 流 4,225 B > frenet 省下的 2,171 B（净亏，
  66,864 B = 26.95 bpv）。
- **修复**：把局部系变换换成**可逆整数 lifting**：R（rows=n,t,b）分解为
  Euler ZYX = Rz(α)Ry(β)Rx(γ)（双端同一 R、bit-exact），每个 2D 旋转用 3 个
  lifting shear `u += round(a·v)` 实现（a=(c−1)/s, b=s），整数域严格可逆；
  近 π 旋转先做 `R(θ)=N·R(θ−π)`（N=两坐标取负）归一化，否则 a→∞ 使 rounding
  放大数千倍（实测未归一化时 forward 误差 3243 quant；归一化后 2.23 quant）。
  standalone 20,000 随机 case：inverse_mismatch=0。
- 因此不再需要 exact correction 流（sv=8 留作兼容，不采用）。

## 6. PGS gate-queue traversal 重写预研（spike 结论）

**F1（PGS 现状）**：如 §3.1 —— 忠实路径的 6 级 tag priority 恒等于 2.0（tag 不演化、
from_null 不置位），实际顺序 = 堆插入序。`impl/RD/RDErrorMetric.h:61,86` 可直接取证。

**F2（isPoly 不可推导）**：每轮 BFS 访问 326,656 个 face 才标出 19,784 个 patch face；
enumerative floor Σlog₂C(F_r,G_r)=12,617 B vs 实际 13,154 B（95.9% 效率，无熵余量）。
`ISPOLY_DERIVE` 实测 patch face 在 layer mesh 上全是三角形（splitDeg3=3298/3298，
nonSplitPoly=0），decoder `ISPOLY_PROBE` 可推导 ones=0 ⇒ **只能靠 replay，不能靠网格推导**。

**F3（杠杆足够）**：若仅去掉 isPoly、其余分量不变：
`(64,604−13,154)×8/19851 = 20.73 bpv`（已过硬顶 21.96）；
若叠加本轮 sv=7：`(62,490−13,154)×8/19851 = 19.88 bpv`（过理想 20.27）。
⇒ PGS 重写不需要几何预测器也足以达标；geometry 改进是余量。

**F4（真正的 blocker：decoder 确定性）**：`HalfedgeSelectionQueue` 的
`MinErrorComparator` 只比 `error`（RD 恒 2.0）⇒ pop 序 = 插入序/堆布局；要 decoder 复现，
必须复刻 encoder 的全局 select/eliminate 循环（含 pool 分配序、proxy normalize、fan 三角化）。
RDStrict 的 20+ phase 已证明这是硬骨头：sideinfo-free replay topology 23/39698（Phase 33）、
direct ring replay 是唯一 PASS 但代价 sideinfo（Phase 31/35）、face rank/poolId locator
全失败（Phase 44–47）。**关键设计点**：把 tie-break 换成可双端复算的 canonical key
（如 proxy 顶点量化整数坐标字典序），而不是依赖 poolId/堆序 —— 这是与 RDStrict 路径的本质区别。

**实现拆解（1,720–2,780 LOC，4–6 轮，高风险）**：

### 8.4 P3 设计 spike 结论（下一步决策输入）
1. **可行边界**：P2 投影 20.737（sv=3）已过硬顶，19.885（sv=7）过理想 ⇒ P3 值得投入。
2. **canonical order 已验证可实现**：消除顺序可按「量化位置 key」100% 复原
   （19,784/19,784）——但这是 *encoder 侧事后映射*；decoder 需要在**生长中的网格**上
   复现同一 selection 顺序。
3. **当前 global priority queue 不能直接 replay**：队列 init 一次 + lazy invalidation，
   pop 序依赖初始（fine）网格的重算顺序与堆布局（tag/conquered 在 init 时都不存在，
   见 8.2），decoder 在 coarse 起点拿不到这些状态。**必须把 encoder 选择换成
   确定性 A&D 式 gate-queue conquest**：FIFO gateQueue + candidate 取 gate face 环 +
   `SelectionPolicy::candidateScore` 打分、同分按环序 —— 框架已有现成
   `src/selection/GreedySelector.cpp`（当前生产路径未用）+ PCATM-strict 的
   `makeSelectionPolicy` 可作模板。
4. **P3 路线（LOC/风险/轮次）**：
   - P2a（~200-300 LOC，中，0.5 轮）：RDAlgorithm::selector() env-gated → Greedy；
     RetriOverride RD_TAG 分支按 env 放开 Greedy + 设置 **确定性 seed**（避免
     `GreedySelector::selectSeed` 的 rand() 回退）；encoder-only 测 artifact。
   - P2b（~300-500 LOC，中，0.5-1 轮）：gate-queue 收集器：按 gate 顺序发
     (valence, residual)，去掉 isPoly locator；新 sv 承载（需 registry/scope 决策）。
   - P3（~900-1,400 LOC，**高**，2 轮）：decoder 镜像 replay（insert 语义 +
     conquered/gateQueue/score 双端一致）；难点仍是 MCGAL mutation 语义对齐
     （RDStrict Phase 33/44-47 证据）。
   - P4（~200-400 LOC，中，0.5-1 轮）：predictor/容器 + 门禁。
   ⇒ 总 1,600-2,600 LOC / 4-5 轮。
5. **待 Lead 决策**：(a) 是否批准 `impl/common/RetriOverride.h` 的 1 行
   updateAfterEliminate 开关（用于 P1 动态打分实验，env-gated）；(b) P2a/P2b 需要的
   selector 切换/确定性 seed 是否允许在 RetriOverride 内 env-gated 配置；
   (c) 新 sv/stream 布局是否复用 sv=7/8 还是新开 sv（涉及 storage registry，scope 外）。
